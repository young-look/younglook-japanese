> 把本机里的日语视频和字幕，变成可以拆开、查询、练习的日语学习素材。

Obsidian 插件 · Windows / macOS / Linux · Obsidian 1.5.0 以上

![学习页](docs/img/0-study-view.png)

## 它能帮你做什么

看番剧学日语，最可惜的是台词一遍就过去了。洋流日语把你**已经在电脑里**的视频和字幕沉淀成你的学习素材：

- 停在任意一句，反复听、反复读
- 点词查义、查读音，生词自动收进生词本
- 跟读录音，回放对比原声
- 每一句都能随手写自己的笔记，登录后存在账号里，换设备也能看到

视频和字幕文件**原地不动**，插件只记路径 —— 不复制、不上传。

## 安装

BRAT 是 Obsidian 官方的「测试版插件」工具，装了它之后拉取新版由 BRAT 负责（插件自身不做任何更新检查）。全程约 2 分钟，下面每一步都配了图，照着点就行。

### 第 1 步：打开 Obsidian 设置

- **macOS**：点屏幕顶部菜单栏的 **Obsidian → Preferences…（偏好设置）**
- **Windows / Linux**：点左下角的**齿轮图标**

![第 1 步：打开设置](docs/img/1-obsidian-settings.png)

### 第 2 步：关掉「安全模式」

设置窗口左侧选 **第三方插件**，点右上角的 **「退出发布模式」** 按钮（有的版本显示为「退出受限模式」，或是一个开关，关掉即可）。

> 这一步是必须的：新装的 Obsidian 默认开着安全模式，不关的话后面装不了任何社区插件。

![第 2 步：退出发布模式](docs/img/2-quit-mode.png)

### 第 3 步：打开社区插件市场

在「第三方插件」页，点 **社区插件市场** 右边的 **「浏览」**。

![第 3 步：打开社区插件市场](docs/img/3-open-market.png)

### 第 4 步：搜索并安装 BRAT

在市场里搜 **brat**，安装第一个 **BRAT**（作者 ttfhacker），然后**启用**它。

![第 4 步：搜索 BRAT](docs/img/4-search-brat.png)

### 第 5 步：打开 BRAT 的添加面板

BRAT 启用后，**左侧栏会出现 BRAT 的图标**，点它，选择第一条命令：

> **Plugins: Add a beta plugin for testing (with or without version)**

（中文界面显示为「Plugins: 添加一个用于测试的 beta 插件」之类的条目，认准 **Add a beta plugin** 就行）

![第 5 步：点 BRAT 图标](docs/img/5-click-brat-icon.png)

### 第 6 步：粘贴洋流日语的仓库地址

在弹出的对话框里粘贴：

```
young-look/younglook-japanese
```

然后点 **「添加插件」**，等几秒下载。

![第 6 步：添加仓库](docs/img/6-install-younglook.png)

### 第 7 步：完成

右上角弹出通知 **The plugin has been registered with BRAT**，就装好了。左侧栏出现**海獭图标**，点它打开学习页。

第一次查词时会提示下载日语分词词典（约 17MB，只下这一次，之后完全离线），点「下载词典」即可。

![第 7 步：安装成功](docs/img/7-install-success.png)

## 装好之后做什么

1. 点左侧栏**海獭图标**打开学习页，列表里有一条**「示例」**，点「开始学」会先问要不要下载示例素材（约 4MB，只下这一次，下载后可离线学）
2. 导入自己的素材：学习页右上角点 **「导入视频」** → 选视频文件和字幕文件 → 填个名字，搞定
3. 想查词：点句子里的单词；想听读音：点「提示」（第一次会下载分词词典，之后完全离线）
4. 想要 AI 解析和发音评估：点右上角**个人中心** → 账户页，选「内置模型」或填上你自己的 API Key，选谁用谁

![导入视频](docs/img/8-import-video.png)

## 常见问题

**必须登录 / 付费吗？**
不。不登录也能用本地功能（导入、拆句、查词、笔记）。AI 功能（解析、仿写、跟读、助手问答）才需要模型：可以用**自带 API Key**（免费，请求直连你的供应商，不经过我们），也可以用内置模型（按量扣余额，可随时切换）。

**我的视频和字幕会被上传吗？**
不会。视频和字幕留在原处，插件只记路径，内容不上传。

**为什么只有桌面端？**
插件要读你电脑上的视频文件，Obsidian 移动端做不到。

**为什么社区插件市场里搜不到？**
还没上架。上架前用上面的方式安装，功能完全一样；插件**不会自行更新**，升级时用 BRAT 重新装一次，上架后在商店里点更新。

**词典是什么？**
日语分词用的词典（约 17MB），第一次查词时自动下载，之后完全离线。

## 联网与数据

插件**不收集使用行为**：没有第三方统计、没有广告、没有埋点 SDK。所有网络请求都发生在
你主动使用某个功能时，用途如下。

**会连接的服务器**

| 连到哪 | 什么时候 | 为了什么 |
| --- | --- | --- |
| 洋流服务器（`younglook.cc`） | 登录账号、同步学习记录、用**内置模型**做 AI 解析/仿写核对/跟读核对/助手问答、下载词典与示例素材 | 这些功能本身就在服务器上算或存 |
| 你自己的模型供应商 | 只在你自己填了 API Key（BYOK）并选了它时 | 请求**直连**你的供应商，不经过我们 |
| GitHub | 你通过 BRAT / 社区商店安装或更新时 | 由 BRAT / 商店自己拉取，**插件不会自行下载或替换自己的代码** |

**会存到服务器上的东西**

登录账号后才有：

- 账号：邮箱或手机号、昵称、头像
- 学习记录：作品名与集号、学习进度、生词、你自己写的句子笔记
- AI 用量：场景、token 数、费用（**不含**台词原文）

**不需要登录也会有的一条**：

- 安装记录：你把日语词典或示例素材**装成功**时，插件上报一次「装了什么、资源版本、
  插件版本」。这次请求本身还会带来源 IP，服务器会连同这条记录一起存下来，
  **只用来按 IP 去重、估算有多少人装上了这些资源**（同一个网络下的多个人会算成一个，
  所以是个约数）。它不关联账号、不关联学习记录，也不含任何文件内容。
  想删掉这一条，发信到 `info@younglook.cc` 说明即可。

**不会上传的东西**

- 视频与字幕**文件**（插件只记本机路径）
- 服务端**不保存台词原文**

**删除数据**：在个人中心退出登录只会断开连接；要删除账号与云端数据，请用账号邮箱
发信到 `info@younglook.cc`，我们在 7 个工作日内处理。

完整的隐私政策见 [younglook.cc/privacy](https://younglook.cc/privacy)。
